# Phase L Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the dead-code the analyzer already finds reach the report, without letting the ~452 known-noise findings in with it.

**Architecture:** Three coupled changes and three independent ones. S9 adds a
sixth *fine* file role, `fixture`, that maps to coarse `test`, so our own
planted-vulnerability corpora stop emitting findings. S8a tightens
`call_graph.find_dead_functions` so pytest-named functions and overrides of
external base classes are no longer called dead. S8b then wires `dead_import`
and `dead_function` into `formatted_issues` in `analyze_single_file`, resolving
each bare name to a line and a snippet at the report layer, and bumps the cache
version. F12/F13/H1 are unrelated hygiene.

**Tech Stack:** Python 3 stdlib `ast` (the analysis layer takes no runtime
dependencies), pytest, React + TypeScript + Vite, vitest.

**Spec:** `docs/superpowers/specs/2026-09-04-phase-l-design.md`

## Global Constraints

- Interpreter is `venv/Scripts/python.exe` at the **repo root**, never `backend/venv`.
- Frontend typecheck is `npm run typecheck` (`tsc -b`). `tsc --noEmit` checks **zero files**.
- The analysis layer is **stdlib-only**. No new runtime dependency (`CONSTRAINTS.md` §7).
- **Never** lower a benchmark threshold to make the gate pass (§11).
- Stage **explicit paths**. Never `git add -A` or `git add .` (§2).
- **No AI attribution** in any commit message, PR body, tag or release (§1).
- Never push unless asked (§3).
- One logical change per commit (§9). One commit per task ID below.
- Every new fixture must be **observed failing** against pre-fix code before the fix lands.
- The coarse `file_type` contract stays exactly three values: `production`, `test`, `non_code`.

- [ ] **Step 3: Add the location resolver**

In `repository_review_engine.py`, module level, after `_cache_manager = CacheManager()`:

```python
# ----------------------------------------------------------
# S8: resolve dead-code names to locations
# ----------------------------------------------------------
# The detector returns bare names — `unused_imports` is a list of dotted
# import paths, `unused_functions` a list of simple names. Widening it to
# carry line numbers would break six assertions across the test suite and
# phase4_validation for no gain here, because this layer already holds the
# source. So the names are resolved back to lines here, once per file.
# ----------------------------------------------------------

def _dead_code_locations(code: str):
    """Return ({importee: lineno}, {func_name: lineno}) for `code`.

    Import keys are rebuilt exactly as call_graph.build_import_graph builds
    `ImportEdge.importee`, so they match what the detector reported. Returns
    two empty dicts for unparsable source; never raises.
    """
    try:
        tree = ast.parse(code)
    except SyntaxError:
        return {}, {}

    imports: Dict[str, int] = {}
    functions: Dict[str, int] = {}
    for node in ast.walk(tree):
        if isinstance(node, ast.Import):
            for alias in node.names:
                imports.setdefault(alias.name, node.lineno)
        elif isinstance(node, ast.ImportFrom):
            module = node.module or ""
            for alias in node.names:
                key = f"{module}.{alias.name}" if module else alias.name
                imports.setdefault(key, node.lineno)
        elif isinstance(node, (ast.FunctionDef, ast.AsyncFunctionDef)):
            functions.setdefault(node.name, node.lineno)
    return imports, functions
```

Add `import ast` to the imports at the top of the file if it is not already there.
